## 这版把各家额度监控收进「服务商」页，Key 也能在里面直接填

- **「服务商」页一家一卡**：DeepSeek 余额、Z.ai 额度、OpenCode Go 额度从「设置」页搬到「服务商」页，与 SiliconFlow、小米 MiMo、火山引擎以及你自助添加的厂商排在一起。每张卡片都能直接填入 API Key 并点「保存」（写入 DSH 凭据中心，不回显），并开关「启用监控」「在侧边栏展示」、调整抓取间隔（最短 3 分钟），卡片内同时显示该家当前余额或额度明细。
- **在侧边栏看额度更省事**：勾选「在侧边栏展示」后，对应额度芯片就出现在侧边栏底部——宽列显示名称与金额或额度百分比，折叠态为迷你芯片，悬浮看完整明细；开关打开后即使数据还在加载也会先占位显示。
- **内置三家改为按家开关**：SiliconFlow、小米 MiMo、火山引擎原来共用一个总开关，现在可以逐家启用 / 停用、逐家决定是否上侧边栏；原来的总开关设置会自动沿用到三家，不用重新设置。
- **「设置」页只留与统计相关的内容**：模型统计重定向、会话徽标与账本操作；所有额度相关的偏好统一在「服务商」页。
- **火山引擎与小米 MiMo 也能在此页填 Key**：火山按提示填 Access Key ID 与 Secret Access Key 两项；小米 MiMo 可填 API Key，或改用浏览器 Cookie（二选一）。
- 本次无统计口径变化，历史数据不受影响。
